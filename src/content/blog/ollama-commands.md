日常用到的命令不多，记住这几个就够。下面所有的命令都在终端里敲。

## 下载与运行

```bash
ollama pull qwen2.5:7b   # 只下载，不聊天
ollama run qwen2.5:7b    # 没有就先下，然后进对话
```

`run` 其实是"没有就拉、有就跑"，所以大多数时候直接用 `run` 就行。

## 看本机有哪些

```bash
ollama list   # 已下载的模型
ollama ps     # 正在跑的模型（占着内存的那个）
```

`ps` 在你想腾内存的时候有用——能看见哪个模型还赖在内存里没释放。

## 删除与复制

```bash
ollama rm qwen2.5:7b          # 删掉，腾空间
ollama cp qwen2.5:7b myqwen   # 复制成一个好记的名字
```

模型下到本机是占硬盘的，不用的删掉就行，以后想用再 `pull` 回来。

## 看模型详情

```bash
ollama show qwen2.5:7b
```

会打出底层信息、参数、模板。哪天回答怪怪的，可以先 `show` 一下确认是不是模型本身的问题。

## 模型名到底怎么读

格式是 `<名称>:<尺寸>`。尺寸是指模型的"参数规模"——简单理解成模型有多大、多聪明：

- `qwen2.5:0.5b` 很小，快但笨
- `qwen2.5:7b` 日常够用
- `qwen2.5:14b` / `:32b` 更强，但更吃资源

不写尺寸就默认 `:latest`（通常是该系列最新的中等大小）。

尺寸后面还能跟量化，比如 `qwen2.5:7b-q4_K_M`。`q4` 省内存、略损精度；`q8` 更准、更占空间。笔记本一般选 `q4_K_M` 平衡。

## 怎么选尺寸

先在 7B 量级试，回答够用就别往大了上；要是卡顿或者内存报警，就换小一号，或者把量化调低一档。别一上来就追最大，本地跑模型内存才是硬门槛。

`ollama push` 是把模型推到 Ollama 的模型库，需要账号，个人基本用不到，提一句免得看到困惑。
