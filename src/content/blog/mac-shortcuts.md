快捷键不用全记，常用的那几个用多了自然就记住了。下面按场景列出来，先挑每天都会用到的那几个练。

## 最常用

| 快捷键 | 作用 |
| :--- | :--- |
| `Cmd + C` | 复制 |
| `Cmd + V` | 粘贴 |
| `Cmd + X` | 剪切（仅文字） |
| `Cmd + Z` | 撤销 |
| `Cmd + Shift + Z` | 重做 |
| `Cmd + A` | 全选 |
| `Cmd + F` | 查找 |
| `Cmd + W` | 关闭当前窗口 |
| `Cmd + Q` | 退出应用 |
| `Cmd + Tab` | 切换应用 |
| `Cmd + \`` | 同应用内切换窗口 |
| `Cmd + H` | 隐藏当前应用 |
| `Cmd + M` | 最小化窗口 |

## 文件操作

| 快捷键 | 作用 |
| :--- | :--- |
| `Cmd + N` | 新建窗口 |
| `Cmd + O` | 打开文件 |
| `Cmd + S` | 保存 |
| `Cmd + Shift + S` | 另存为 |
| `Cmd + Delete` | 移到废纸篓 |
| `Cmd + Shift + N` | 新建文件夹 |
| `Cmd + I` | 显示文件简介 |
| `Cmd + D` | 复制所选文件 |
| `Space` | 快速预览文件 |

## 截图

| 快捷键 | 作用 |
| :--- | :--- |
| `Cmd + Shift + 3` | 全屏截图，存到桌面 |
| `Cmd + Shift + 4` | 区域截图，存到桌面 |
| `Cmd + Shift + 4` 再按 `Space` | 窗口截图，存到桌面 |
| `Cmd + Shift + 5` | 截图工具栏（也能录屏） |
| `Cmd + Ctrl + Shift + 3` | 全屏截图到剪贴板 |
| `Cmd + Ctrl + Shift + 4` | 区域截图到剪贴板 |

## 系统

| 快捷键 | 作用 |
| :--- | :--- |
| `Cmd + Space` | Spotlight 搜索 |
| `Cmd + ,` | 当前应用偏好设置 |
| `Cmd + Option + Esc` | 强制退出应用 |
| `Cmd + Shift + Q` | 注销用户 |
| `Cmd + Option + 电源键` | 睡眠 |
| `Ctrl + 电源键` | 显示关机选项 |

## 文本编辑

| 快捷键 | 作用 |
| :--- | :--- |
| `Cmd + ←` | 跳到行首 |
| `Cmd + →` | 跳到行尾 |
| `Option + ←` | 跳到上一个词 |
| `Option + →` | 跳到下一个词 |
| `Cmd + ↑` | 跳到文档开头 |
| `Cmd + ↓` | 跳到文档结尾 |
| `Option + Delete` | 删除前一个词 |
| `Cmd + Delete` | 删除到行首 |

## 浏览器（Safari / Chrome）

| 快捷键 | 作用 |
| :--- | :--- |
| `Cmd + T` | 新建标签页 |
| `Cmd + W` | 关闭标签页 |
| `Cmd + Shift + T` | 恢复刚关的标签页 |
| `Cmd + L` | 定位到地址栏 |
| `Cmd + R` | 刷新 |
| `Cmd + [` | 后退 |
| `Cmd + ]` | 前进 |
| `Cmd + 数字` | 切到第 N 个标签页 |

## 终端

| 快捷键 | 作用 |
| :--- | :--- |
| `Ctrl + C` | 终止当前命令 |
| `Ctrl + A` | 光标到行首 |
| `Ctrl + E` | 光标到行尾 |
| `Ctrl + U` | 删除整行 |
| `Ctrl + R` | 搜历史命令 |
| `Ctrl + L` | 清屏 |
| `Tab` | 自动补全命令或路径 |
