在站点右上角有一个放大镜图标。点一下（或者按 `Ctrl` / `⌘ + K`）就会弹出一个搜索框，输入关键词，下面实时列出匹配的文章标题和一小段摘要。这就是本站的搜索。

它背后的工具叫 **Pagefind**。

## 搜索工具：Pagefind 是什么

Pagefind 是一个专门为静态网站做的全文搜索引擎。它的工作方式和你平时习惯的"网站搜索"不太一样：

- 它不是在某个服务器上跑一个搜索服务，也不是连数据库；
- 它是在你**构建网站的时候**，把已经生成好的 HTML 页面读一遍，提取文字、建好索引，把索引文件一起打包进站点；
- 读者在浏览器里搜索时，索引直接在浏览器本地被查询，不需要再访问任何服务器。

所以对一个托管在 Vercel 这类"只托管静态文件"的平台来说，Pagefind 很合适：它不要求你有后端。

## 读者怎么搜

两种方式都能打开搜索框：

- 点页面右上角的搜索图标；
- 按快捷键 `Ctrl + K`（Windows / Linux）或 `⌘ + K`（macOS）。

打开后输入关键词，结果会实时刷新，最多显示前 8 条，每条带标题和一小段摘要。按 `Esc` 关闭。

注意：搜索只在**构建后的站点**上能用。本地用 `astro dev` 起开发服务器时，点搜索会提示"搜索仅在生产环境可用"——这不是坏了，而是开发模式下还没生成索引。部署上线（或本地 `npm run preview`）之后就能正常搜。

## 站长怎么搭起来

分两步。

### 第一步，构建时生成索引

`package.json` 里 `build` 脚本跑完 `astro build` 之后，会接着跑一个 `postbuild`：

```bash
npm run build
```

它做两件事：先由 Astro 把 Markdown 渲染成 `dist/` 下的静态页面，再由 Pagefind 扫描整个 `dist/` 目录，生成索引文件放到 `dist/pagefind/`。

如果你只想重新生成索引、不想重新构建整套站点，也可以单独跑：

```bash
npx pagefind --site dist
```

### 第二步，页面里接上搜索框和查询逻辑

站点有一个 `Search.astro` 组件，负责渲染搜索按钮和一个全屏遮罩层。点击按钮会依次做这几件事：

1. 动态加载 `/pagefind/pagefind.js`（就是 Pagefind 在构建时生成的入口文件）；
2. 告诉它站点的根路径 `baseUrl: '/'`，让它能正确拼出文章的真实链接；
3. 监听输入框，每次输入都调用 `pagefind.search(关键词)`；
4. 拿到结果后取前 8 条，读出每条的标题和摘要，渲染成可点的链接。

为了避免打字太快时频繁查询，输入做了 200 毫秒的防抖（debounce）。打开的快捷键（`Ctrl` / `⌘ + K`）和关闭（`Esc`）也在这里处理。

## 为什么这么做

- **零后端**：纯静态托管就能全文搜索，和本站的部署方式完全契合；
- **索引跟着站点走**：每次重新构建，索引都基于最新内容重新生成，不会过时；
- **体验轻**：查询在浏览器本地完成，打开快、没有服务器延迟。

代价也有：搜索只存在于构建产物里，所以开发预览（`astro dev`）中点不开——这点前面提过。另外索引是在站点发布那一刻生成的，所以改了文章之后需要重新部署，搜索结果才会包含新内容。

---

想在自己搭的同类站点上复刻，做法是：选一个"构建期建索引"的静态搜索工具（Pagefind 是其中之一），在构建脚本里接上它，再在页面放一个能加载它、调用 `search()` 的搜索框。
