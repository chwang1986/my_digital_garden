Ollama 是一个开源工具，让你能在自己的电脑上直接跑大语言模型（也就是 ChatGPT、Claude 背后那类"会聊天的 AI"）。不用注册云端账号，不用每次调用都联网付费，装好之后，模型就躺在你机器里。

## 为什么要在本地跑

平时我们用的很多 AI 能力，背后是调各家云平台的接口。那样很省事，但也有几个绕不开的问题：

- **数据要出本机**。你发给云端的内容，会先经过别人的服务器。
- **要联网、要按量付费**。断网就用不了，用得多账单就涨。
- **换模型不自由**。你想试另一个开源模型，往往得再接一套新的接口。

Ollama 把这些反过来：模型跑在本地，数据留在自己机器上，离线也能用，一次装好之后随便换模型，不按次收费。

## 它到底怎么用

装完 Ollama（macOS / Linux / Windows 都支持），最常用的就是两行命令(在命令行中执行)：

```
ollama pull llama3     # 先把模型下载到本地
ollama run llama3      # 直接进入对话
```

`ollama run` 之后就是一个本地聊天窗口，和你在网页上聊天差不多，只是背后跑的是你本机的模型。想看装了哪些模型，用 `ollama list`。

模型来自 Ollama 自己的模型库，里面有 Llama、Mistral、Gemma、Qwen 等一堆开源模型，直接按名字拉就行。

## 它不只是个聊天框

Ollama 装好后会顺手在本机起一个服务（默认地址 `localhost:11434`）。也就是说，它不只是命令行里能聊，你写的程序、其它工具也能通过这个地址调用本地的模型——这就让它从"玩玩"变成了能接进自己工作流的一部分。后面几篇会专门讲这块。

## 适合谁

如果你符合下面任意一条，Ollama 值得装：

- 在意隐私，不想把内容发给第三方；
- 想离线也能用 AI；
- 想本地折腾不同的开源模型，做实验或搭自己的小工具；
- 不想被各家 API 的按量计费绑住。

## 一点实在的提醒

本地跑模型是吃资源的活儿。模型越大，需要的显存和内存越多。像 7B、8B 这种小模型，普通笔记本基本能跑；再往上，就得看显卡够不够。

所以入门别一上来就拉最大的，先拿小模型跑通整个流程，确定顺手了，再按机器能力往上加。
